# VAB Controlling – Workshop-Demo

Öffentliche, vollständig statische Workshop-Demo für GitHub Pages. Einstieg: `index.html`.

## Sicherheit und Daten

- Alle dargestellten Kennzahlen und Zeiträume sind **synthetische Beispieldaten**.
- Keine produktiven ITCS-/AFZS-Dateien, Vertragsdokumente, personenbezogenen Daten oder Zugangsdaten enthalten.
- Kein Server, kein Upload und keine externe API notwendig.
- Vertragsstaffeln werden nur illustrativ gezeigt und stellen keine abrechenbaren Forderungen dar.

## Veröffentlichung

1. Diesen Ordner `workshop-demo` in den Branch `main` des Repositories `ralfbauerdammbach-cmd/Georg-Dashboard` übernehmen.
2. In GitHub unter **Settings → Pages** bei **Build and deployment → Source** die Option **Deploy from a branch** auswählen.
3. **Branch: main**, **Folder: / (root)**, dann **Save**.
4. Nach der Veröffentlichung die Adresse öffnen:
   `https://ralfbauerdammbach-cmd.github.io/Georg-Dashboard/workshop-demo/`

Für einen direkten Einstieg in die Vertragsauswertung:
`https://ralfbauerdammbach-cmd.github.io/Georg-Dashboard/workshop-demo/#betrieb-qualitaet`
