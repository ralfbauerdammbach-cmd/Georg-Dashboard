# Georg-Dashboard

Webbasiertes Arbeitscockpit zur Unterstützung der Abrechnung von Verkehrsunternehmen sowie zur Verwaltung von Ausschreibungen und Verkehrsverträgen im VAB-Verbund.

## Projektziel

Das Georg-Dashboard soll die tägliche Arbeit in einer zentralen und übersichtlichen Weboberfläche zusammenführen.

Die Anwendung soll insbesondere unterstützen bei:

- Abrechnungen der Verkehrsunternehmen
- Prüfung von Leistungs- und Kilometerdaten
- Verwaltung von Verkehrsverträgen
- Preisgleitungen und Vertragsänderungen
- Ausschreibungen und Vergabeverfahren
- Aufgaben, Fristen und Wiedervorlagen
- Dokumenten- und Kommunikationsverwaltung
- späteren Auswertungen über Qlik

## Technische Grundrichtung

- Ubuntu Server
- Docker Compose
- Python-Webanwendung
- PostgreSQL
- browserbasierte Benutzeroberfläche
- GitHub für Quellcode und Dokumentation
- Qlik ausschließlich für Auswertungen

## Projektstatus

**Phase 1 – Fachliche Konzeption und Pilotplanung**

Derzeit werden die tatsächlichen Arbeitsabläufe, Datenquellen, Prüfschritte und Anforderungen gemeinsam mit dem zuständigen Mitarbeiter aufgenommen.

## Grundsatz

Das Dashboard soll eine einheitliche Arbeitsoberfläche bilden. Andere Systeme und Dienste dürfen im Hintergrund unterstützen, sollen für den Benutzer jedoch möglichst nicht sichtbar sein.

## Sicherheit

Dieses Repository darf keine echten:

- Kennwörter
- Zugangsdaten
- personenbezogenen Daten
- Rechnungsunterlagen
- vertraulichen Vergabeunterlagen
- produktiven Vertragsdokumente

enthalten.
